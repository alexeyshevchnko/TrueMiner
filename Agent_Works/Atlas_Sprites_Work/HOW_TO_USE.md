# HOW_TO_USE — инструмент Atlas Outline Transfer (пиксельная маска)

Инструмент редактора Unity для формирования результата по пиксельной цветовой маске
строго по заданным правилам (никакого распознавания контуров, flood fill, автогенерации
обводки или эвристик соседних тайлов).

---

## 1. Где находится инструмент

- Скрипт: `Assets/Editor/AtlasOutlineTransfer.cs` (класс `AtlasOutlineTransferWindow`).
- Это Editor-инструмент: в игру и игровые сцены не подключён, игровые компоненты не затрагивает.
- Резервные копии: `Agent_Works/Atlas_Sprites_Work/backup/`.
- Документация направления: `Agent_Works/Atlas_Sprites_Work/`.

## 2. Как открыть окно

В Unity открыть меню **Tools → Atlas Outline Transfer**.
Появится окно «Atlas Outline Transfer».

## 3. Три входных атласа

Назначьте все три поля из окна проекта:

| Поле | Назначение |
|---|---|
| **Source Mask Atlas** | Источник цветовой маски. Читается только для чтения. |
| **Source Content Atlas** | Источник изображения/контента. Читается только для чтения. |
| **Result Atlas** | Атлас, в который пишется результат. |

Важно: Source Mask Atlas и Source Content Atlas инструментом НЕ изменяются никогда —
из них только читаются пиксели. Результат пишется исключительно в Result Atlas.

## 4. Цвета маски (строго по RGB)

Сравнение цветов маски выполняется строго по RGB. Альфа-канал маски не участвует.

| Цвет маски (RGB) | Смысл | Что пишется в Result Atlas |
|---|---|---|
| `#F777F9` (розовый) | прозрачность | полностью прозрачный пиксель `(0, 0, 0, 0)` |
| `#000000` (чёрный) | обводка | цвет из настройки **Outline Color**, альфа 255 |
| `#FF0000` (красный) | область контента | соответствующий пиксель из Source Content Atlas без изменения RGBA |
| любой другой цвет | неизвестный | предупреждение, пиксель не подменяется произвольным цветом |

Если пиксель маски не соответствует ни одному из трёх заданных цветов, инструмент
выводит понятное предупреждение и не подменяет его произвольным цветом.

## 5. Настройка Outline Color

| Настройка | По умолчанию | Смысл |
|---|---|---|
| Outline Color | Чёрный `(0, 0, 0)` | Цвет обводки, который записывается в Result Atlas вместо пикселей маски `#000000`. Альфа всегда 255. |

## 6. Определение размера результата

Инструмент сравнивает размеры Source Mask Atlas и Source Content Atlas:

- **Ширина результата** = минимальная ширина двух исходных атласов.
- **Высота результата** = минимальная высота двух исходных атласов.

Обрабатывается только эта общая область координат. Изображения не масштабируются,
координаты пикселей не меняются.

## 7. Первый проход — формирование результата

Инструмент обходит Source Mask Atlas попиксельно по координатам X/Y в общей области:

- цвет `#F777F9` → в Result Atlas записывается `(0, 0, 0, 0)`;
- цвет `#000000` → в Result Atlas записывается Outline Color с альфой 255;
- цвет `#FF0000` → из Source Content Atlas копируется соответствующий пиксель без изменения RGBA;
- любой другой цвет → предупреждение, без подмены.

## 8. Второй проход — устранение прозрачных пикселей внутри контента

Повторный обход Source Mask Atlas, только для координат, где цвет маски `#FF0000`:

- Если альфа пикселя Result Atlas равна 255 — ничего не делать.
- Если альфа меньше 255 (включая полностью прозрачные) — найти ближайший полностью
  непрозрачный пиксель (Alpha = 255) в Source Content Atlas по евклидову расстоянию
  и скопировать его целиком (все четыре канала RGBA) в текущую координату Result Atlas.

Поиск ближайшего пикселя ограничен областью атласа, не используются полупрозрачные пиксели
как источник, пиксели с Alpha = 255 не меняются. Если ближайший непрозрачный пиксель не
найден — пиксель остаётся без изменений и выводится предупреждение со статистикой.

## 9. Как выполнить Analyze

Нажмите кнопку **Analyze**. Инструмент:

1. Проверяет, что все три атласа назначены.
2. Читает пиксели Source Mask Atlas и Source Content Atlas (только для чтения;
   если у текстуры выключен Read/Write, файл читается с диска во временную текстуру —
   ассет и его импорт-настройки не меняются).
3. Определяет итоговый размер (минимум ширины/высоты двух исходных атласов).
4. Считает статистику над общей областью координат:
   - размеры исходных атласов;
   - итоговый размер;
   - количество пикселей каждого из трёх цветов маски (#F777F9, #000000, #FF0000);
   - количество пикселей маски с неизвестными цветами;
   - количество скопированных пикселей контента;
   - количество пикселей обводки;
   - количество прозрачных пикселей, заменённых во втором проходе;
   - количество пикселей, для которых не удалось найти непрозрачный источник.
5. Показывает результат в окне и в Console.

Анализ не изменяет никаких файлов и может запускаться сколько угодно раз.

## 10. Как проверить предварительный результат (Preview)

Нажмите кнопку **Preview** — отобразится временное изображение результата в размере
итоговой области. Ассеты в этот момент не изменяются, запись в файлы не выполняется.
Preview позволяет визуально сравнить результат с ожидаемым поведением перед Transfer.

## 11. Как выполнить Transfer

Нажмите кнопку **Transfer**. Инструмент:

1. Обязательным первым шагом создаёт резервную копию файла Result Atlas
   (см. раздел 12). Если копию создать не удалось — запись отменяется.
2. Выполняет оба прохода и пишет результат только в файл Result Atlas.
3. Реимпортирует результат в Unity (AssetDatabase.ImportAsset с ForceUpdate).
4. Выводит в окне и Console отчёт: размер результата, статистику по проходам,
   путь результата и путь резервной копии.

Повторный Transfer безопасен — он перезаписывает Result Atlas по текущим правилам.

## 12. Где находятся результаты и резервные копии

- Результат — файл Result Atlas, который вы назначили в поле (например
  `Assets/Resources/TerrariaTiles_Sprites/outline_transfer/outline_result.png`),
  обновлённый через реимпорт в Unity.
- Резервная копия создаётся до записи в папке:
  ```
  Agent_Works/Atlas_Sprites_Work/backup/<имя_файла>_<дата-время>.backup.<расширение>
  ```
  Копия никогда не перезаписывается (добавляется метка времени / уникальный суффикс).
- Временные превью и иллюстрации: `Agent_Works/Atlas_Sprites_Work/preview/`.

## 13. Как восстановить Result Atlas из резервной копии

Чтобы откатить:

1. Откройте в проводнике папку `Agent_Works/Atlas_Sprites_Work/backup/`.
2. Скопируйте нужный `.backup`-файл поверх текущего файла Result Atlas с исходным именем.
3. Верните фокус в Unity — оно само выполнит reimport (или ПКМ по файлу → Reimport).
4. `.meta` не менять — восстанавливается только содержимое файла текстуры.

Удалять резервные копии не рекомендуется: они позволяют всегда вернуться к исходному
состоянию.

## 14. Частые ошибки и что они значат

| Сообщение | Что делать |
|---|---|
| «Назначьте все три атласа…» | Перетащите в окне Source Mask Atlas, Source Content Atlas и Result Atlas. |
| «…файл не найден…» | Убедитесь, что все три атласа существуют в проекте и доступны по пути. |
| «…не удалось загрузить изображение…» | Проверьте формат файла (поддерживается чтение PNG и других форматов через Unity); при необходимости включите Read/Write Enabled в Import Settings. |
| «Result Atlas не имеет пути ассета…» | Назначьте в поле Result Atlas ассет из окна проекта, а не случайную текстуру. |
| «Ошибка создания резервной копии…» | Запись отменена — проверьте права на папку `Agent_Works/Atlas_Sprites_Work/backup/`. |
| «пикселей маски с неизвестным цветом…» | В маске есть пиксели, не совпадающие с `#F777F9`, `#000000` или `#FF0000` — проверьте маску. |
| «пикселей контента не имеют непрозрачного источника…» | В красной области (`#FF0000`) есть пиксели с альфой < 255, для которых в Source Content Atlas нет полностью непрозрачного пикселя — они остаются без изменений. |

## 15. Безопасность данных (кратко)

- Source Mask Atlas и Source Content Atlas только для чтения — никогда не изменяются.
- Результат пишется исключительно в Result Atlas.
- Перед перезаписью Result Atlas создаётся резервная копия.
- PNG и `.meta` исходных атласов не меняются; импортные настройки исходных текстур не меняются без необходимости.
- Инструмент не выполняет никаких операций над другими атласами.
- Окно никогда не запускает перенос само — только по нажатию кнопки Transfer.

## 16. Алгоритм в одну строку

«Для каждой координаты в общей области: `#F777F9` → прозрачность `(0,0,0,0)`;
`#000000` → Outline Color с альфой 255; `#FF0000` → скопировать пиксель из Source Content
Atlas; затем во втором проходе прозрачные/полупрозрачные пиксели внутри `#FF0000`
заменяются ближайшим непрозрачным пикселем (Alpha=255) из Source Content Atlas по
евклидову расстоянию. Никаких контуров, flood fill, эвристик или автоисправлений.'
