## Сессия 13 (2026-11-23): Atlas Outline Transfer Editor Tool + коммит

### Задание
Editor-инструмент переноса чёрной 2-пиксельной обводки блоков из одного атласа в другой
(Filed: `Assets/Editor/AtlasOutlineTransfer.cs`, меню `Tools → Atlas Outline Transfer`).
Именно перенос существующей обводки пиксель в пиксель — без генерации новой и без масштабирования.

### Реализация
- Новый окно `AtlasOutlineTransferWindow` (EditorWindow, вне игровых компонентов):
  - входы: Source Outline Atlas / Destination Atlas (ObjectField + имя и размеры рядом);
  - обнаружение: Outline Color (чёрный), Color Tolerance 0.12 (≈±30/255 на канал),
    Outline Thickness 2 px, порог прозрачности (alpha/255 < 0.03 считается прозрачным);
  - кнопки: Analyze / Transfer Outline / Preview (+ Clear Preview, «Открыть папку backup»);
  - отчёт анализа: размеры и совпадение, число пикселей обводки, число связных
    непрозрачных областей (блоков), число исключённых внутренних чёрных пикселей.
- Алгоритм обнаружения: маска непрозрачных пикселей; послойный BFS (4-связность)
  от прозрачной границы даёт глубину d каждого пикселя; обводка = чёрные (в допуске)
  пиксели с d ≤ 2. Чёрные пиксели глубже — внутренние детали — НЕ копируются.
  Никаких произвольных эвристик к границам блоков не добавлено ( они объективно
  выводятся из прозрачности).
- Перенос: только выявленные пиксели записываются в целевой атлас по исходным координатам;
  уже совпадающие пиксели не перезаписываются (безопасный повторный запуск);
  пиксели вне обводки сохраняются байт в байт; реимпорт результата через AssetDatabase.
- Защита данных: исходник только читается (GetPixels либо файл с диска во временную
  RGBA32-текстуру, если Read/Write выключен — как TerrariaTilesSpriteExtractor);
  обязательная резервная копия целевого файла в `Agent_Works/Atlas_Sprites_Work/backup/`;
  при ошибке копии перенос отменяется; PNG-целевой файл обновляется in-place (только
  содержимое текстуры, `.meta` не трогаются); для неперезаписываемых форматов результат
  сохраняется отдельным `*_outlined.png` рядом (с понятным предупреждением);
  окно никогда не запускает перенос само; состояние анализа не переживает перезапуск окна.
- Автосохранение состояния анализа между открытиями отсутствует (требование соблюдено).

### Проверки
- Компиляция/типизация: csc против модулей Unity 6000.6 (`UnityEngine/UnityEditor`)+
  netstandard2.1 — COMPILE_OK (0 ошибок). Batch-компиляция Unity невозможна (проект открыт
  редактором) — Unity сама завершит импорт при фокусе; список замечаний не изменился.
- Верификация алгоритма на реальном атласе `Assets/Resources/TerrariaTiles.png`
  (1024×1024) — та же математика в PowerShell: обнаружено **3814** пикселей внешней
  обводки; **3611** чёрных внутренних деталей исключены; симуляция переноса в
  `TerrariaTiles.png` без обводки восстановила его **пиксель в пиксель (0 отличий из 1048576)**.
  Иллюстрация: `preview/outline_transfer_simulation.png` (слева — цель без обводки, справа — после переноса).
- Финальный прогон в Unity-редакторе (Analyze → Preview → Transfer) остаётся
  пользовательским шагом: редактор открыт пользователем; см. TEST_REPORT и REMAINING_ISSUES.

### Git
- Коммит `Add Atlas Outline Transfer Editor Tool` (инструмент + .meta, документация,
  preview-иллюстрация). Служебный лог неудачной batch-попытки не коммитился.
