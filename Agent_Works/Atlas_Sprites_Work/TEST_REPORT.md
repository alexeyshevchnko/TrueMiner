## Сессия 14 (2026-11-23): исправление точности Outline Transfer (тестовые атласы outline_transfer)
| Проверка | Результат |
|---|---|
| Данные теста | `outline_src.png` 288×270 (920 чёрных, 1011 маркеров #F777F9, 0 полупрозрачных); `outline_result.png` = прежний результат переноса (826 чёрных, без маркеров) |
| Причина пропусков | Установлена по данным: 94 потерянных пикселя лежали на глубине d=3..4 от прозрачного края, потому что маркеры #F777F9 формируют непрозрачный кант МЕЖДУ прозрачностью и обводкой; прежний порог «d ≤ 2» их отрезал (27 кластеров: углы и тонкие отрезки контура) |
| Что НЕ является причиной | Допуск цвета (чёрный 0,0,0 совпадал), alpha/полупрозрачность (её нет в тесте), обход координат (dest == src по найденным пикселям), «не строго 2px» (обводка 2px, но прижата к маркерам) |
| Исправление | Маркерный цвет исключён из маски-барьера (не обводка, не преграда); UI: Exclude Marker Color + Marker Color (#F777F9 по умолчанию) |
| Обнаружение после исправления (outline_src) | **920/920** чёрных (d ≤ 2 после исключения маркера), внутренних исключено 0, маркеров 1011 — не трогаются |
| Регрессия на большом TerrariaTiles.png | 3821 обнаружено (3814 до правки), внутренних 3604 по-прежнему исключены — правило не захватывает внутренние детали |
| Перенос (dest = outline_result) | Записано **94/94** пикселя; после переноса по всем обводочным координатам dest == src пиксель в пиксель (0 несоответствий); лишних чёрных нет; розовые маркеры не тронуты (0) |
| Непрерывность/толщина | Проверено пиксельно: все 27 бывших пропусков восстановлены на своих координатах, цвет берётся из исходника; толщина и форма обвод == исходник (dest после переноса совпадает с src по обводке полностью) |
| Идемпотентность | Повторный перенос: **0 записей** |
| Компиляция | csc (Unity 6000.6 модули + netstandard2.1) — COMPILE_OK |
| Иллюстрации | `preview/outline_transfer_fixed.png`; `preview/outline_transfer_before_after_zoom.png` (src / fixed + 5×-зум проблемного участка) |
| Финальный прогон кнопками в Unity-редакторе | Остался пользователю (редактор занят владельцем проекта); алгоритм и настройка по умолчанию верифицированы на реальных тестовых PNG той же математикой |
