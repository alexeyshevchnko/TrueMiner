# artifacts — снимки результата

Все изображения получены из **оригинальных** тайлсетов `Tiles_0` / `Tiles_1`
(дампы вырезаны из `Assets/Resources/TerrariaTiles.png`) и кадров, посчитанных
текущей реализацией `TerrariaFraming`.

| Файл | Что показывает |
|---|---|
| `terrain_preview.png` | вся тестовая карта 64×36: рельеф, трава, каменные жилы, пещера, столб, отдельные блоки, вертикальная и горизонтальная полосы, **полоса камня в земле с выходом в пустоту с обеих сторон** |
| `zoom_strip.png` | увеличение проблемного участка (x 0..22, y 13..22, ×8): левый торец `(162,0)`, середина `(144..180,180)`, правый торец `(216,0)` |
| `zoom_vein.png` | увеличение каменной жилы (x 0..18, y 28..36, ×7) — проверка, что слияние камня с землёй не сломалось |
| `framing_sheet_stone.png` | атлас **всех 81** комбинаций соседей для камня (по 3 значения на каждую из 4 сторон), с подписями `S/M/E` и порядком `up/down/left/right` |
| `framing_sheet_dirt.png` | то же для земли |
| `tiles_0_dump.png`, `tiles_1_dump.png` | дампы оригинальных спрайтов 287×269 (сетка кадров 18 px), по ним проверялась геометрия |
