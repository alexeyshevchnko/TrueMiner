## 3. Технический долг (вне рамок задачи, для будущих сессий)
- **Три бинарных префаба** (`PoolPefubs/Boom.prefab`, `PoolPefubs/gui/RedLbl.prefab`, `Prefubs/gui/bagItem.prefab`)
  остаются в бинарной сериализации: правки возможны только через Unity API (как сделано в этой задаче).
  При желании привести всё к тексту: выбрать ассеты → Inspector → сериализация текстом (аккуратно, с ревью диффа).
- **CS0618-остатки в сторонних демо-скриптах** больше не присутствуют в Console (компиляция чистая), но при
  следующем мажоре Unity устаревшие API станут ошибками — тогда повторить подход этой задачи
  (замены документированы в TECHNICAL_NOTES §1).
- `MainSceneLight.unity` — альтернативная сцена; в игру не загружается, очищена от потерянных компонентов (4 шт.).
